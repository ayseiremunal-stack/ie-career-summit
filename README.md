# IE Career Summit 2026

IE Career Summit 2026, HTML, CSS ve JavaScript kullanılarak geliştirilmiş responsive bir front-end portfolyo projesidir.

Proje, endüstri mühendisliği öğrencilerine yönelik iki günlük kurgusal bir kariyer etkinliği web sitesini simüle etmektedir.

## Özellikler

* Responsive web tasarımı
* İki günlük interaktif etkinlik programı
* Açılır/kapanır SSS bölümü
* Başvuru formu
* JavaScript ile kullanıcı etkileşimleri
* LocalStorage ile başvuru verilerinin tarayıcıda saklanması
* Sayfa içi yumuşak geçişler

## Kullanılan Teknolojiler

* HTML5
* CSS3
* JavaScript
* LocalStorage

## Projenin Amacı

Bu proje; front-end geliştirme, responsive tasarım, DOM işlemleri ve JavaScript ile kullanıcı etkileşimleri konularındaki becerileri geliştirmek ve portfolyo kapsamında sergilemek amacıyla hazırlanmıştır.

> **Not:** IE Career Summit 2026 kurgusal bir etkinliktir. Projede yer alan etkinlik, konuşmacı ve şirket bilgileri portfolyo çalışması kapsamında oluşturulmuştur.
